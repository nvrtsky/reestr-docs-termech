# Подпись кнопки добавления документа

AC-1: основная кнопка полного реестра имеет точную подпись «+ Добавить документ» и открывает существующий мастер.
AC-2: подсказки и справка используют ту же подпись.
NG-1: не изменять сохранение, права доступа и кнопку подтверждения внутри мастера.
NG-2: сохранить исходные незакоммиченные изменения пользователя.

Проверка: typecheck, build, браузерная проверка подписи и открытия мастера на синтетических данных. Скриншот: docs/evidence/add-document-label-20261023/registry.png.
