# Единая библиотека полей — 27.10.2026

В редакторе типа документа встроенные и дополнительные поля теперь отображаются одним списком: название и код, тип данных, разделы использования, действие. Общий поиск работает по всем этим значениям без учёта регистра и пробелов по краям запроса. При отсутствии совпадений показано пояснение.

Встроенные реквизиты помечены «Уже в карточке» и недоступны для повторного добавления. Дополнительное поле использует существующий ключ, тип и варианты списка; после выбора кнопка меняется на «Добавлено». Повторное нажатие не добавляет то же поле второй раз. Значения документов, политики доступа и настройки уникальности этот выпуск не меняет.

## Проверка

- `npm run typecheck` и `npm run build`.
- `scripts/verify-field-library-browser.mjs`: общий список, поиск по четырём признакам, встроенные поля, повторное добавление, сохранение ключей/типов/вариантов, пустая выдача, ширина 600 px, отсутствие ошибок и записей API.
- `scripts/verify-section-browser.mjs`: регрессия настроек разделов, защищённых прав администратора, денежных значений и защиты от повторного создания.
- Браузерные проверки используют синтетический API. Они не создают реальные документы и не изменяют настройки.
- Скриншоты: `docs/evidence/field-library-20261027/`.

## Выпуск и откат

Меняется только `/usr/share/nginx/html/legacy/index.html` в образе frontend, основанном на текущем рабочем образе. Backend, база и настройки Marketplace сохраняются. Скрипт выпуска сверяет базовый образ и HTML, сохраняет настройки контейнера и предыдущий образ на сервере, проверяет готовность и неизменность остальных контейнеров. При ошибке выполняется откат.

Ручной откат на сервере: `python3 /opt/reestr-docs/releases/field-library-20261027/deploy.py rollback`.
