Задача: https://github.com/nvrtsky/reestr-docs-termech/issues/39

Причина: .registry-content имеет position:relative и начинается ниже верхней части Реестра. Общий embedded-стиль превращает фиксированную оболочку карточки в absolute; она привязывалась к .registry-content. Воспроизведён пропуск 121px сверху. При открытой карточке этот контейнер теперь static, содержащий блок — .registry-shell. Фон покрывает всю оболочку, а только правая панель ограничена существующей видимой областью iframe. При закрытии карточки :has перестаёт действовать.

Исправление накладывается отдельным проверяемым overlay при сборке; исходная сохранённая production-разметка не меняется.
