# Минимальные права пользователей

Реестр использует `user_brief` для ID, ФИО, должности и подразделения. Проверка администратора выполняется по `profile.ADMIN`; приглашение сотрудников и изменение профилей не требуются. Отсутствующий EMAIL не блокирует работу реестра.

Проверки запуска, установки и состояния встроек принимают `user_brief`, `user_basic` и `user` как достаточный уровень чтения профиля. Прочие обязательные права продолжают проверяться отдельно. Права `task` и `tasks` совместимы как названия скоупа задач.

При публикации версии запросить `user_brief`. После установки проверить запуск реестра, список ответственных, административную роль, роли подразделений и вкладки документов в CRM. Не заменять проверку рабочих операций скриншотами с ответами-заглушками API.
