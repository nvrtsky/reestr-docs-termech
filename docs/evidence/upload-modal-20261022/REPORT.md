# Окно загрузки документа — 22.10.2026

Задача: https://github.com/nvrtsky/reestr-docs-termech/issues/43

Окно «Новый документ» встраивалось в позиционированный блок под шапкой, хотя координаты видимой области измерялись от всего приложения. Поэтому окно сдвигалось вниз на высоту шапки. Исправлена точка отсчёта окна; на узких экранах также исключена горизонтальная прокрутка фона при открытой форме.

Критерии AC-1–AC-4 проверены в Chrome на синтетических данных: iframe с длинной карточкой, форма с 24 дополнительными полями, 1366×768 / 1024×600 / 390×700, до и после прокрутки родителя. Окно по центру видимой области; заголовок и нижние кнопки доступны; колесо у границ формы не прокручивает родителя. Проверены полный реестр и изменение размера окна. Отдельно прошла проверка карточки документа и предпросмотра PDF. JavaScript-ошибок нет. `npm run typecheck` и `npm run build` прошли.

До исправления: [окно уходит ниже экрана](before/modal-1366-top.png).
После исправления: [верх формы](after/modal-1366-top.png), [нижние поля](after/modal-1366-top-bottom.png), [узкий экран](after/modal-390-top-bottom.png).

Проверки используют реальные браузерные координаты и события колеса, API отвечает синтетическими данными. Проверка реальной карточки CRM под пользовательской авторизацией пока не выполнена: автоматическая проверка доступа отклонила открытие компании за пределами ранее разрешённой тестовой сделки.

Выпуск заменяет только HTML во frontend-образе, основанном на текущем рабочем образе. Backend, пользовательские данные, права и настройки не изменяются (NG-1, NG-2). Предыдущий образ и конфигурация сохранены. Откат: `python3 /opt/reestr-docs/releases/upload-modal-20261022/deploy.py rollback`.
