# Доказательные экраны ТЗ v2.0

Дата синхронизации: 29.07.2026.

Эти снимки получены из локально собранного интерактивного прототипа и используются
в Google Doc «Техническое_задание_Реестр», встроенной вкладке ТЗ и проверке NVR-270.

| Файл | Сценарий |
| --- | --- |
| `bulk-upload.png` | Массовая загрузка и заполнение полей каждой строки |
| `related-documents.png` | Двусторонние связи договора и зависимых документов |
| `finance-sync.png` | Итог сделки, валюты, курс ЦБ РФ и синхронизация Bitrix24 |
| `html-tz-overview.png` | Обзор редакции: источники, обозначения и объём сверки |
| `html-tz-changes.png` | Подробный журнал: «было / принято / проверка» для каждого изменения |
| `html-tz-conflicts.png` | Семь снятых противоречий в формате «было → стало» |
| `html-tz-device-scope.png` | Явное исключение мобильной версии и отдельной авторизации |
| `desktop-on-phone.png` | Десктопный макет при открытии с телефона |
| `tz-comments.png` | Комментарий, цитата и ответ в HTML-ТЗ |

HTML-вкладка использует метки `[v2]`, `[отложено]`, `[оценка]` и `[не входит]`.
В первой фазе нет мобильной версии: телефон открывает десктопный интерфейс,
а пользователь входит только через учётную запись Bitrix24.

К тексту ТЗ можно привязать локальную ветку обсуждения: выделить фрагмент,
написать комментарий, ответить, закрыть или восстановить ветку. Прототип хранит
обсуждения в `localStorage` текущего браузера.
